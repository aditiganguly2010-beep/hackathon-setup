# AI Friday Season 2 – Qualifier

### Interactive Legacy System Health Monitor for IT Application Maintenance

**PROBLEM STATEMENT**

IT application maintenance teams managing legacy systems face difficulties monitoring system health due to fragmented logs, outdated monitoring tools, and lack of real-time insights. This leads to inconsistent detection of system degradation, delayed issue resolution, and increased downtime risks. The volume of logs and metrics from multiple legacy components complicates manual analysis. Existing monitoring dashboards lack generative AI capabilities to synthesize data and provide actionable summaries. Maintenance teams need an interactive AI-driven health monitor that aggregates legacy system data, highlights anomalies, and suggests maintenance priorities. This improves operational reliability and reduces service disruptions.

**Data Considerations:**

Requires legacy system logs in text or JSON formats, performance metrics from monitoring tools, and historical incident records. Data may be fragmented and requires preprocessing such as parsing, normalization, and noise filtering. Privacy involves securing sensitive system data. Synthetic data generation can simulate legacy system anomalies and normal operation patterns. Consider using synthetic or anonymized data where appropriate. Ensure data quality and relevance to the problem context.

**SOLUTION EXPECTATIONS**

The application features an interactive web UI dashboard aggregating legacy system data, highlighting health scores, detected anomalies, and prioritized maintenance actions. Core features include multi-source data integration, AI-driven anomaly detection, natural language summaries of system status, and exportable maintenance reports. KPIs include 85% anomaly detection accuracy and 30% reduction in issue identification time. GenAI capabilities synthesize disparate data into actionable insights. The prototype enables effective legacy system monitoring and maintenance decision support. Feel free to explore creative solutions that align with the problem context and objectives.
